# 交互体验契约

## 核心交互原则

列表与详情同屏，点击行就地展开，不做整页跳转。任何写操作都有即时反馈，失败时保留用户已填内容。

## 全局状态流转

- 加载态：表格骨架屏优先，保持列宽与页面结构可见
- 空状态：说明当前缺什么，并给出下一步动作，例如凭证页提示先添加一个凭证
- 错误态：就地展示错误原因，输入内容不丢失，提供重试入口

## 响应式与断点

- 桌面端：左侧固定导航，内容区多栏布局，表格完整展示
- 移动端：导航收成顶部抽屉，内容单列，表格转为卡片列表，触控热区不小于 44px

## 无障碍基准

键盘可达全部交互元素，Escape 关闭弹层，焦点可见，正文与背景对比度不低于 4.5:1
