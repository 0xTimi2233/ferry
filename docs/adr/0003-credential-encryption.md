# 凭据静态加密采用信封加密

上游密钥与订阅令牌必须落盘才能跨重启存活，明文存储一旦数据文件泄漏即等于密钥泄漏。因此采用信封加密：每条凭据用随机数据密钥加密后入库，数据密钥本身再加密一次落盘，主密钥存操作系统凭据库，启动时自动获取。

## 备选方案

- 明文落盘只靠文件权限。实现最简，但备份、同步、误传都会把密钥带出去
- 主密钥由用户口令派生。安全性取决于口令强度，代价是每次启动都要输入口令解锁
- 整库加密。密钥管理粒度粗，改一条凭据要重写整个文件

## 影响

换机器或跨平台迁移时操作系统凭据库不通用，主密钥需要重新导入。密钥自动获取意味着安全性边界从口令转移到机器：拿到宿主机或凭据库访问权即可解密。加密后无法在数据库里按凭据明文检索，需要额外的索引字段。
